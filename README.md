# 3D 列印考試・抱佛腳 APP

iPAS 3D 列印積層製造工程師（初級）考前衝刺用。考試日期：115/11/14（六）。

## 怎麼開

**線上版（手機、電腦都能用）：https://paul800901.github.io/ipas-3dp-exam/**

下載到電腦用：雙擊「▶ 開啟考試APP.html」，用 Chrome 或 Edge 開就能用，不用網路、不用帳號。
作答進度存在這台電腦的瀏覽器裡；換電腦或換瀏覽器，進度不會跟過去。

## 裡面有什麼

| 內容 | 數量 | 來源 |
|---|---|---|
| 115 年第一次真題 | 兩科各 50 題，共 100 題 | 官方公告試題（只有答案） |
| 官方樣題 | 科目一 25 題、科目二 70 題 | 官方學習指引（有答案＋官方解析） |
| 重點卡 | 12 張主題卡 | 依上面兩份資料整理 |
| AI 模擬題 | 508 題，每科 6 份模擬卷（共 12 份） | Claude Opus 5.5 依官方學習指引（115/10/28 版）出題，GPT-6.1 Sol 逐題對照講義核對 |

每題都有「白話解說」和「一句話記」。真題的白話解說是另外寫的（官方沒有解析）；樣題另外附官方詳細解析可以展開看。

功能：重點卡、刷真題、依主題練、錯題＋標記（答錯的連續答對 2 次才移出；猜對或不熟的題目可按「🔖 標記」，要自己取消才會移出）、模擬考（每科 50 題、75 分鐘，作答中也能標記；只抽官方題）、AI 模擬卷（練習沒看過的新題，可計時模擬考或逐題看解說）。

AI 模擬題的審核紀錄（2026-11-12）：四批各 50 題，答案全部與核對者獨立判答一致；共 18 題的題幹前提或解說用語依核對意見修正（答案未變）。AI 題不是官方考題，若與官方資料不同，以官方為準。

第二輪（2026-11-12，第 3、4 份，專考講義細節、數值與比較）：四批各出 50 題，答案全部與核對者獨立判答一致；14 題因與既有題目重複、只出自參考文獻或講義前後數值不一致而刪除，7 題換成新考點，26 題修正題幹前提或解說（答案未變），最後保留 186 題。

冷知識清理（2026-11-12）：考生回饋只能硬背的題目讓人受挫；實查 115 年真題 100 題沒有公司、年份、人名、軟體由來這類題目，因此刪除 17 題冷知識 AI 題。每題在 `ai_questions.json` 記有所屬卷號，刪題不會讓其他題換卷。

第三輪（2026-11-12，第 5、6 份，觀念判斷題，最接近真題）：先逐題分析 115 年真題的出題方式（科目一以技術判斷、比較、原因、情境選技術、安全處置為主；科目二以參數因果、缺陷改善、擺放、選材為主，數字很少），再照此出題。四批各 50 題，答案全部與核對者獨立判答一致；核對時另檢查是否偏冷知識或比真題艱深。因前兩輪已涵蓋不少相同觀念，刪除 61 題重複或過深題目，36 題補前提或修正解說，最後保留 139 題。AI 卷選單依「最接近真題 → 綜合 → 講義細節（比真題難）」排序並標示。

模擬考交卷後會顯示「各主題答對率」，最弱的主題排最上面，可直接開該主題重點卡。

## 資料夾

- `app/`：APP 本體（`index.html`、`app.js`、`style.css`、`data.js`、`img/` 題目附圖）
- `data/`：官方原始 PDF（學習指引兩冊、115 年真題兩科）與轉出的文字（不放在 GitHub，請從下方官網下載）
- `tools/`：把 PDF 轉成題庫的程式，以及白話解說原稿
  - `parse_guides.py`、`parse_exam.py`：從 PDF 擷取題目、答案、附圖
  - `explain_exam.json`、`explain_guide.json`：每題的主題、白話解說、一句話記
  - `lessons.json`：重點卡內容
  - `ai_questions.json`：AI 模擬題（`basis` 欄是出題依據的講義行號與原文摘錄，行號對應 `data/guide1.txt`、`data/guide2.txt`）
  - `build_data.py`：合併成 `app/data.js`

修改解說後重新產生：

```
python -I tools/build_data.py
```

題目、答案與官方解析的著作權屬原單位；白話解說與重點卡為個人整理，僅供備考參考，若與官方資料不同，以官方為準。
